# KitDuel (Spigot/Paper 1.21+)

ปลั๊กอินท้าดวลเลือก Kit + ปาตี้ดวลทีม — 13 kits: macepvp, **macerocket**, cpvp, cutpvp, uhc, smp, ffa, nethpot, diapot, axepvp, archer, **sword**, **spearpvp**

## ติดตั้ง
1. ติดตั้ง Multiverse-Core แล้วสร้างโลก: `/mv create pvp normal`
2. คอมไพล์: `mvn clean package` → ได้ `target/KitDuel.jar` (ต้องใช้ JDK 21)
3. ใส่ jar ใน `plugins/` แล้วรีสตาร์ท
4. (แนะนำ) ยืนในโลก pvp ตั้งสนาม: `/duel setspawn arena1 1` และ `/duel setspawn arena1 2`
   (ตั้งได้หลายสนาม ดวลพร้อมกันได้) ถ้าไม่ตั้ง จะใช้จุดเกิดของโลก pvp

## วิธีเล่น
- ผู้เล่นได้ "ดาบท้าดวล" ตอนเข้าเซิร์ฟ (หรือ `/duel sword`)
- ถือดาบ **คลิกขวาที่ผู้เล่น** → หน้าต่างกระจกเลือก Kit
- อีกคนถือดาบ **คลิกขวาที่คนท้า** → วาปไปโลก pvp, นับถอยหลัง แล้วสู้
- จบดวล: วาปกลับ + คืนไอเทม/เลือด/EXP/ตำแหน่งเดิมทั้งหมด

## ปาตี้ดวล (ทีมมากกว่า 2 คน)
1. `/party create` (หรือ `/paty create`) → สร้างปาตี้ และหัวหน้าได้ **ดาบปาตี้ดวล**
2. ถือดาบปาตี้ **คลิกขวาผู้เล่นที่ไม่มีปาตี้** = เชิญเข้าปาตี้ (หรือ `/party invite <ชื่อ>`) → อีกฝ่ายพิมพ์ `/party accept`
3. ถือดาบปาตี้ **คลิกขวาผู้เล่นของปาตี้อื่น** → เลือก Kit → ส่งคำท้าปาตี้
4. หัวหน้าอีกฝ่ายถือดาบปาตี้ **คลิกขวาที่หัวหน้าผู้ท้า** (หรือ `/party acceptduel`) → ทุกคนวาปเข้าสนามพร้อมกัน
5. ทีมไหนตายหมดก่อนแพ้ — คนตายดูต่อเป็นสเปกเตเตอร์, ตีเพื่อนร่วมทีมไม่ได้, จบแล้วทุกคนได้ของ/ตำแหน่งเดิมคืน

`/party help` · `create` · `invite` · `accept` · `deny` · `leave` · `kick` · `promote` · `disband` · `list` · `sword` · `acceptduel`
ตั้งค่าได้ใน `config.yml` หมวด `party:` (`max-size`, `invite-expire-seconds`, `require-equal-size`)

## Kit ใหม่
- **macerocket** — Elytra + Firework Rocket x192 + Mace (Density V / Wind Burst) บินสูงแล้วทุบ มีเสื้อ Netherite สำรองในช่อง 9 และ Slow Falling
- **sword** — Netherite Sword Sharp V + Bow + Shield + Totem
- **spearpvp** — หอก Netherite (Lunge III) + ดาบ + Shield *(หอกมีใน Minecraft 1.21.11+ ถ้าเซิร์ฟเวอร์เก่ากว่านี้จะใช้ Trident แทนอัตโนมัติ)*

## คำสั่ง
`/duel sword [ผู้เล่น]` · `/duel leave` · `/duel setspawn <สนาม> <1|2>` · `/duel delarena <สนาม>` · `/duel arenas` · `/duel reload`
สิทธิ์: `kitduel.use` (ทุกคน), `kitduel.admin` (OP)

## ระบบกันบัค
- เซฟสถานะผู้เล่นลงไฟล์ (`plugins/KitDuel/states`) — เซิร์ฟล่ม/ผู้เล่นหลุดกลางดวล ของไม่หาย คืนให้ตอนเข้าใหม่
- ผู้เล่นออกกลางดวล = อีกฝ่ายชนะ
- ตายแล้วไม่ดรอป ไม่เห็นหน้าจอตาย (respawn อัตโนมัติ)
- บล็อกที่วาง/น้ำ/ลาวาที่ไหล ถูกคืนสนามหลังจบ, ระเบิดไม่ทำลายบล็อก, ไฟไม่ลาม
- เคลียร์ ลูกธนู/คริสตัล/ไอเทมตก หลังจบ
- ห้ามดรอปของ/ใช้คำสั่ง/วาปออก/ใช้พอร์ทัล ระหว่างดวล
- กันคนนอกมาตีผู้ดวล, หมดเวลา = เสมอ
- ดาบท้าดวล/ดาบปาตี้ ใช้ตีผู้เล่นนอกดวลไม่ได้ และทิ้งไม่ได้ (กันของหาย/กันตีกันในล็อบบี้)
- จบดวลสนามหนึ่ง จะไม่ลบคริสตัล/ไอเทมของดวลอื่นที่ยังเล่นอยู่ในสนามใกล้กัน
